> **ما ستتعلمه:** ستتمكّن من تثبيت أوبن كلاو (OpenClaw) على نظام Linux Ubuntu بنجاح، وفهم جميع المتطلبات الأساسية والخطوات التفصيلية. كما ستتعرّف على كيفية التحقق من التثبيت والقيام بالإعدادات الأولية لبدء استخدام منصة الأتمتة الذكية.

## مقدمة

أصبحت الأتمتة الذكية جزءاً لا غنى عنه في حياة المطورين والمهندسين الحديثين. منصة أوبن كلاو (OpenClaw) تمثّل حلاً قويّاً وموثوقاً لأتمتة العمليات والتكامل بين الأنظمة المختلفة. نظام Linux Ubuntu، بفضل استقراره وسهولة استخدامه، يعتبر المنصة المثالية لتشغيل أدوات الأتمتة المتقدمة.

في هذا الدليل الشامل، سنرشدك عبر كل خطوة من خطوات تثبيت أوبن كلاو على Linux Ubuntu. سواء كنت مبتدئاً أو محترفاً، ستجد هنا كل ما تحتاج إليه لتشغيل منصة الأتمتة هذه بكفاءة واحترافية.

## المتطلبات الأساسية قبل التثبيت

قبل البدء في عملية التثبيت، تأكّد من توفر المتطلبات الأساسية على نظامك. هذه المتطلبات ليست معقدة، لكنها ضرورية لضمان عمل أوبن كلاو بدون مشاكل.

أولاً، تحتاج إلى نسخة حديثة من Linux Ubuntu. يُفضّل استخدام Ubuntu 20.04 LTS أو الإصدارات الأحدث، حيث توفر الاستقرار والدعم الطويل الأمد. ثانياً، يجب أن يكون لديك صلاحيات المسؤول (Root) أو القدرة على استخدام الأمر sudo. ثالثاً، تحتاج إلى اتصال إنترنت مستقر وسرعة كافية لتحميل الحزم المطلوبة.

فيما يلي جدول يوضح المتطلبات التفصيلية:

| المتطلب | النسخة الدنيا | النسخة المفضلة | الملاحظات |
|---------|-------|-------|----------|
| Linux Ubuntu | 18.04 | 22.04 LTS أو أحدث | LTS توفر استقرار أفضل |
| Python | 3.8 | 3.10 أو أحدث | مطلوب لتشغيل أوبن كلاو |
| Node.js | 14.0 | 18.0 أو أحدث | للمكونات التفاعلية |
| Git | 2.25 | آخر إصدار | لاستنساخ المستودع |
| RAM | 2 GB | 4 GB أو أكثر | لأداء أفضل |
| مساحة التخزين | 500 MB | 1 GB أو أكثر | للتثبيت والملفات المؤقتة |

## خطوات التثبيت التفصيلية

الآن دعنا ننتقل إلى الخطوات العملية لتثبيت أوبن كلاو على نظامك. اتبع هذه الخطوات بالترتيب للحصول على أفضل النتائج.

### الخطوة الأولى: تحديث نظام التشغيل

قبل أي شيء، يجب تحديث قوائم الحزم الموجودة على نظامك. افتح الطرف (Terminal) واكتب الأوامر التالية:

```bash
sudo apt update
sudo apt upgrade -y
```

هذه الأوامر ستتأكد من أن جميع البرامج المثبتة والمكتبات محدثة إلى أحدث إصداراتها.

### الخطوة الثانية: تثبيت المتطلبات الأساسية

بعد التحديث، ننتقل إلى تثبيت المتطلبات الأساسية. اكتب الأوامر التالية بالتسلسل:

```bash
sudo apt install -y python3 python3-pip python3-venv git curl wget
```

ثم قم بتثبيت Node.js:

```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
```

تحقق من تثبيت البرامج بنجاح:

```bash
python3 --version
node --version
git --version
```

### الخطوة الثالثة: استنساخ مستودع أوبن كلاو

الآن حان وقت استنساخ مستودع أوبن كلاو من GitHub. انتقل إلى المجلد الذي تريد تثبيت المشروع فيه:

```bash
cd /opt
sudo git clone https://github.com/openclaw/openclaw.git
cd openclaw
```

### الخطوة الرابعة: إنشاء بيئة افتراضية

إنشاء بيئة افتراضية يعزل مشروعك ويمنع تضارب المكتبات:

```bash
python3 -m venv venv
source venv/bin/activate
```

ستلاحظ أن سطر الأوامر الآن يبدأ بـ (venv)، مما يشير إلى أن البيئة الافتراضية نشطة.

### الخطوة الخامسة: تثبيت حزم Python المطلوبة

قم بترقية pip أولاً ثم ثبّت الحزم المطلوبة:

```bash
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

إذا واجهت أي أخطاء، تأكد من أن ملف requirements.txt موجود في المجلد الرئيسي للمشروع.

### الخطوة السادسة: تثبيت المكونات الأمامية (Frontend)

إذا كان المشروع يحتوي على مكونات واجهة المستخدم (Frontend):

```bash
cd frontend
npm install
npm run build
cd ..
```

## الإعدادات الأساسية والتكوين

بعد التثبيت بنجاح، تحتاج إلى إجراء بعض الإعدادات الأساسية لتشغيل أوبن كلاو بشكل صحيح.

### إنشاء ملف الإعدادات

أنشئ ملف config.env في المجلد الرئيسي للمشروع:

```bash
cp config.example.env config.env
```

ثم قم بتحرير الملف باستخدام محرر نصوص مثل nano أو vim:

```bash
nano config.env
```

أضف المتغيرات البيئية المطلوبة:

```
APP_ENV=development
DATABASE_URL=sqlite:///app.db
SECRET_KEY=your-secret-key-here
API_PORT=5000
```

### تثبيت قاعدة البيانات

إذا كان أوبن كلاو يستخدم قاعدة بيانات:

```bash
python manage.py migrate
```

### إنشاء حساب مسؤول (إن لزم الأمر)

```bash
python manage.py createsuperuser
```

اتبع التعليمات لإدخال اسم المستخدم وكلمة المرور والبريد الإلكتروني.

## بدء تشغيل أوبن كلاو

الآن بعد إكمال جميع خطوات التثبيت والإعدادات، حان وقت بدء تشغيل أوبن كلاو. اكتب الأمر التالي:

```bash
python run.py
```

أو إذا كنت تستخدم طريقة مختلفة:

```bash
gunicorn --workers 4 --bind 0.0.0.0:5000 app:app
```

ستظهر رسالة تؤكد تشغيل التطبيق بنجاح، وستتمكّن من الوصول إليه عبر المتصفح على عنوان http://localhost:5000

إذا كنت تريد تشغيل أوبن كلاو على خادم (VPS)، يمكنك الاطلاع على [تثبيت OpenClaw على VPS](/blog/install-openclaw-vps) للحصول على إرشادات متقدمة.

قوة أوبن كلاو تكمن في قدرتها على التكامل مع أدوات أخرى. يمكنك ربط أوبن كلاو مع GitHub لأتمتة سير العمل. راجع [أتمتة GitHub مع أوبن كلاو](/blog/2026-02-10-github-automation-openclaw) لمعرفة كيفية تحقيق ذلك.

كما يمكنك أتمتة عمليات البريد الإلكتروني باستخدام [أتمتة البريد الإلكتروني](/blog/2026-02-16-email-automation-himalaya) مع أوبن كلاو.

إذا كنت تقارن بين أوبن كلاو وأدوات أخرى مثل Zapier، تحقق من [مقارنة أوبن كلاو مع Zapier](/blog/2026-02-09-openclaw-vs-zapier-comparison).

## استكشاف الأخطاء والمشاكل الشائعة

قد تواجه بعض المشاكل أثناء التثبيت أو التشغيل. إليك بعض الحلول السريعة:

إذا حصلت على خطأ "Permission Denied" عند محاولة تنفيذ الأوامر، استخدم sudo:

```bash
sudo chown -R $USER:$USER /opt/openclaw
```

إذا كانت هناك مشاكل في المكتبات المفقودة:

```bash
pip install --upgrade pip
pip install -r requirements.txt --force-reinstall
```

إذا كان المنفذ 5000 مشغولاً بالفعل:

```bash
FLASK_ENV=development FLASK_APP=run.py FLASK_RUN_PORT=8000 flask run
```

## الأسئلة الشائعة

### سؤال 1: هل يمكنني تثبيت أوبن كلاو على إصدارات Ubuntu أقدم من 20.04؟

**الجواب:** نعم، يمكن تثبيت أوبن كلاو على Ubuntu 18.04، لكن يُفضّل استخدام الإصدارات الحديثة لضمان توافق أفضل مع المكتبات. إذا كنت تستخدم إصدار أقدم، قد تواجه بعض المشاكل في التوافقية، وننصحك بالترقية إلى نسخة LTS أحدث مثل 22.04.

### سؤال 2: ما الفرق بين تثبيت أوبن كلاو على Linux وتثبيته على Windows أو Mac؟

**الجواب:** التثبيت على Linux عموماً أسهل وأكثر استقراراً لأن Linux يوفر بيئة تطوير محلية متطابقة مع بيئة الإنتاج. على Windows و Mac، قد تحتاج إلى استخدام أدوات إضافية مثل Docker أو Virtual Machines. الخطوات الأساسية متشابهة، لكن الأوامر قد تختلف قليلاً.

### سؤال 3: هل أحتاج إلى تثبيت قاعدة بيانات منفصلة مثل PostgreSQL؟

**الجواب:** بشكل افتراضي، أوبن كلاو يأتي مع SQLite وهو كافٍ للتطوير والاختبار. لكن في بيئة الإنتاج، يُنصح بشدة باستخدام PostgreSQL أو MySQL لأداء أفضل وموثوقية أعلى. إذا كنت تريد استخدام قاعدة بيانات أخرى، عدّل DATABASE_URL في ملف الإعدادات.

### سؤال 4: كيف أحدّث أوبن كلاو بعد التثبيت الأولي؟

**الجواب:** للتحديث، انتقل إلى المجلد الرئيسي للمشروع وشغّل الأوامر التالية:

```bash
cd /opt/openclaw
git pull origin main
source venv/bin/activate
pip install -r requirements.txt --upgrade
python manage.py migrate
```

هذه العملية ستجلب أحدث الإصدارات وتطبق أي تحديثات قاعدة البيانات المطلوبة.

### سؤال 5: هل يمكنني تشغيل أوبن كلاو كخدمة نظام تبدأ تلقائياً عند إعادة تشغيل النظام؟

**الجواب:** نعم، يمكنك إنشاء ملف systemd service. أنشئ ملف جديد باسم openclaw.service في /etc/systemd/system/ وأضف المحتوى التالي:

```
[Unit]
Description=OpenClaw Automation Platform
After=network.target

[Service]
Type=notify
User=openclaw
WorkingDirectory=/opt/openclaw
ExecStart=/opt/openclaw/venv/bin/python run.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

ثم فعّل الخدمة باستخدام: `sudo systemctl enable openclaw` و `sudo systemctl start openclaw`
