> **ما ستتعلمه:** ستتعرف على الأوامر الأساسية الضرورية للتعامل مع سطر أوامر أوبن كلاو (OpenClaw)، وكيفية استخدام كل أمر في حالات عملية حقيقية. ستنهي هذا المقال وأنت قادر على تنفيذ مهام الأتمتة الأولى من سطر الأوامر دون الحاجة لواجهة رسومية.

## المقدمة

سطر الأوامر يخيف كثيرين في البداية. أنت تنظر إلى شاشة سوداء وتكتب نصوصاً غريبة، وفجأة تحدث أشياء تتحكم بها. لكن الحقيقة أن سطر الأوامر في أوبن كلاو ليس معقداً، بل هو أسرع طريقة للعمل. لا تقضي وقتاً في النقر على الأزرار، بل تكتب أمراً واحداً ويُنجز العمل.

إذا كنت تريد الانتقال من المستخدم العادي إلى الشخص الذي يتحكم فعلاً بالنظام، فسطر الأوامر هو الخطوة الأولى. سنبدأ من الصفر، مع أمثلة يمكنك تجربتها مباشرة.

## ما هو سطر الأوامر في أوبن كلاو

سطر الأوامر هو واجهة نصية تتفاعل مع نظام أوبن كلاو مباشرة. بدلاً من استخدام أزرار وقوائم، تكتب الأوامر باللغة الإنجليزية (مثل معظم أنظمة البرمجة)، ويقوم النظام بتنفيذها فوراً.

لماذا تستخدمه؟ أولاً، السرعة. الثانية، المرونة. الثالثة، التحكم الكامل. عندما تتقن الأوامر، ستجد نفسك تنجز في دقيقة ما يأخذ عشر دقائق عبر الواجهة الرسومية.

أوبن كلاو توفر واجهة سطرية سهلة لتثبيت الإضافات، وإدارة المهام، وتشغيل سيناريوهات الأتمتة، وحتى تصحيح الأخطاء.

## الأوامر الأساسية التي يجب أن تعرفها

إليك الأوامر التي ستستخدمها يومياً. كل واحد منها بسيط، لكنه قوي.

### جدول الأوامر الأساسية

| الأمر | الوصف | المثال |
|------|--------|--------|
| `openclaw --version` | عرض نسخة أوبن كلاو المثبتة | `openclaw --version` |
| `openclaw init` | تهيئة مشروع جديد في المجلد الحالي | `openclaw init my-project` |
| `openclaw start` | تشغيل خادم أوبن كلاو | `openclaw start` |
| `openclaw login` | تسجيل الدخول بحسابك | `openclaw login --email user@example.com` |
| `openclaw list workflows` | عرض جميع سيناريوهات الأتمتة | `openclaw list workflows` |
| `openclaw run workflow` | تشغيل سيناريو محدد | `openclaw run workflow task-daily-report` |
| `openclaw logs` | عرض السجلات والأخطاء | `openclaw logs --follow` |
| `openclaw config` | إدارة الإعدادات | `openclaw config set timeout 300` |

## شرح مفصل لأهم الأوامر

### أمر التثبيت والتهيئة: init

عندما تريد بدء مشروع جديد، هذا الأمر هو البداية:

```bash
openclaw init my-automation-project
```

هذا يُنشئ مجلداً جديداً باسم `my-automation-project` ويضع فيه ملفات الإعداد الأساسية. ستجد ملف `openclaw.yaml` يحتوي على إعدادات المشروع.

إذا كنت في مجلد موجود بالفعل وتريد تهيئة أوبن كلاو فيه:

```bash
cd my-existing-folder
openclaw init
```

بدون اسم مشروع، يهيئ النظام المجلد الحالي.

### أمر التشغيل: start

هذا الأمر يشغل خادم أوبن كلاو:

```bash
openclaw start
```

عندما تكتبه، ستظهر رسالة تخبرك بأن الخادم يعمل على عنوان معين (عادة `http://localhost:3000`). بعدها تفتح المتصفح وتدخل العنوان.

إذا أردت تشغيله على منفذ مختلف:

```bash
openclaw start --port 8080
```

### أمر عرض سيناريوهات الأتمتة: list workflows

تريد أن ترى جميع السيناريوهات التي أنشأتها؟

```bash
openclaw list workflows
```

ستظهر قائمة بجميع سيناريوهاتك، مع حالة كل واحد (مُفعّل أم معطّل).

### أمر تشغيل سيناريو: run workflow

هنا تشغل سيناريو محدد:

```bash
openclaw run workflow send-daily-emails
```

حيث `send-daily-emails` هو اسم السيناريو. النظام سيشغله فوراً ويظهر النتائج في سطر الأوامر.

إذا أردت تمرير معاملات للسيناريو:

```bash
openclaw run workflow send-daily-emails --recipient-email user@example.com
```

### أمر عرض السجلات: logs

عندما يحدث خطأ ما وتريد أن ترى ماذا حدث:

```bash
openclaw logs
```

هذا يعرض آخر السجلات. إذا أردت متابعة السجلات في الوقت الفعلي (مثل مشاهدة تحديثات حية):

```bash
openclaw logs --follow
```

ستبقى الشاشة مفتوحة وتعرض كل حدث جديد فوراً.

### أمر الإعدادات: config

تريد تغيير إعدادات النظام؟

```bash
openclaw config set timeout 300
```

هذا يعيّن انتظار 5 دقائق (300 ثانية) قبل أن ينقطع الأمر إذا لم ينته.

لعرض جميع الإعدادات الحالية:

```bash
openclaw config list
```

## سيناريو تطبيقي: أتمتة تقرير يومي لمتجر إلكتروني

تخيل أنك تدير متجراً إلكترونياً بسيطاً وتريد تقرير يومي يُرسل لك كل صباح يحتوي على:
- عدد الطلبات الجديدة
- الإيرادات
- العملاء الجدد

إليك كيف تنجز هذا باستخدام أوبن كلاو:

**الخطوة 1: إنشاء المشروع**

```bash
openclaw init ecommerce-daily-report
cd ecommerce-daily-report
```

**الخطوة 2: إنشاء ملف السيناريو**

أنشئ ملفاً اسمه `daily-report.yaml`:

```yaml
name: daily-sales-report
description: Generate and send daily sales report
schedule: "0 8 * * *"
triggers:
  - type: schedule
    time: "08:00"
    timezone: "Asia/Riyadh"

actions:
  - id: fetch-orders
    type: http
    method: GET
    url: "https://your-store-api.com/orders?since=yesterday"
    
  - id: fetch-revenue
    type: http
    method: GET
    url: "https://your-store-api.com/revenue?date=yesterday"
    
  - id: generate-report
    type: template
    template: |
      Daily Report for {{ today }}
      Orders: {{ fetch-orders.total }}
      Revenue: ${{ fetch-revenue.amount }}
      New Customers: {{ fetch-revenue.new_customers }}
    
  - id: send-email
    type: email
    to: "owner@store.com"
    subject: "Daily Sales Report"
    body: "{{ generate-report.output }}"
```

**الخطوة 3: تحميل السيناريو**

```bash
openclaw start
```

ثم في نافذة أخرى:

```bash
openclaw run workflow daily-sales-report
```

**النتيجة:** كل يوم الساعة 8 صباحاً تحصل على بريد بتقرير المبيعات تلقائياً، بدون أن تفعل شيئاً.

هذا مثال بسيط، لكن تخيل تعقيده أكثر: تجميع بيانات من عدة مصادر، معالجتها، حفظها في قاعدة بيانات، وإرسالها إلى عدة أشخاص بصيغ مختلفة.

للمزيد عن الحالات التجارية، اطلع على [أوبن كلاو للمطاعم والكافيهات](/blog/openclaw-restaurants-cafes-automation)، فقد تجد أفكاراً قابلة للتطبيق في نشاطك.

## نصائح مهمة للمبتدئين

قبل أن تنتهي، إليك أشياء تجنب الأخطاء الشائعة:

**التكملة التلقائية:** اضغط `Tab` بعد كتابة جزء من الأمر، وسطر الأوامر سيكمل الباقي. مثلاً:

```bash
openclaw run wor[Tab]
```

سيصير:

```bash
openclaw run workflow
```

**الأخطاء القراءة:** إذا كتبت `openclaw strat` بدلاً من `openclaw start`، سيقول لك "أمر غير معروف". النظام دقيق في الإملاء.

**المساعدة السريعة:** أي أمر لا تتذكره تماماً، أضف `--help`:

```bash
openclaw run --help
```

سيعرض شرح الأمر وجميع خياراته.

**حفظ كلمات المرور:** عند `openclaw login` للمرة الأولى، سيطلب منك كلمة المرور. احفظها في مكان آمن. للمرات القادمة، لن يطلبها (إلا إذا انتهت جلسة العمل).

إذا كنت لا تريد الدخول في التقنيات المعقدة وتريد حلاً جاهزاً يعمل مع أوبن كلاو، فهناك [فارس، المساعد الذكي العربي على تيليجرام](https://fares.arabclaw.com) — يمكنك البدء معه مباشرة دون تثبيت أو أوامر سطرية.

## الأسئلة الشائعة

### سؤال 1: ما الفرق بين openclaw start و openclaw run workflow؟

**الجواب:** `openclaw start` يشغّل الخادم الرئيسي، أي يهيئ النظام ويفتح الباب للعمل. `openclaw run workflow` يشغّل سيناريو محدد داخل هذا الخادم. باختصار: start = إشعال المحرك، run = تشغيل السيارة.

### سؤال 2: هل يمكن تشغيل سيناريوهات متعددة في نفس الوقت؟

**الجواب:** نعم، تماماً. أوبن كلاو تدعم التوازي (parallel execution). يمكنك تشغيل عشرات السيناريوهات في نفس الوقت، والنظام يديرها كلها. الأداء يعتمد على موارد خادمك وتعقيد كل سيناريو.

### سؤال 3: كيف أحذف سيناريو بعد أن لا أحتاجه؟

**الجواب:** استخدم الأمر `openclaw delete workflow workflow-name`. مثال: `openclaw delete workflow old-email-sender`. تأكد من اسم السيناريو الدقيق قبل الحذف لأن العملية غير قابلة للعكس.

### سؤال 4: هل سطر الأوامر يعمل على ويندوز وماك وليناكس؟

**الجواب:** نعم، أوبن كلاو تعمل على الأنظمة الثلاثة. الأوامر متطابقة تقريباً. الفرق الوحيد أن ويندوز قد يتطلب استخدام `openclaw.exe` بدلاً من `openclaw`، لكن في معظم الأحوال التثبيت يعدها تلقائياً.

### سؤال 5: ماذا إذا نسيت أمراً معيناً؟

**الجواب:** اكتب `openclaw` فقط دون أي أمر، وستظهر قائمة بجميع الأوامر المتاحة مع شرح قصير لكل واحد. أو ادخل على [github.com/openclaw](https://github.com/openclaw) حيث الوثائق الكاملة متاحة.

## الخاتمة

سطر الأوامر في أوبن كلاو ليس معقداً، بل هو أداة قوية في يديك. بهذه الأوامر الثماني، تستطيع بناء أتمتات معقدة وتشغيلها وإدارتها.

الخطوة الأولى سهلة: جرّب `openclaw --version` الآن، ثم انتقل إلى `openclaw init` وابدأ مشروعك الخاص. الممارسة هي كل شيء.

للتعمق أكثر، اقرأ [تنسيق وكلاء متعددين مع أوبن كلاو](/blog/2026-03-22-multi-agent-orchestration-openclaw)، وتعرّف على كيفية بناء سيناريوهات متقدمة.

هل لديك أي استفسار؟ اترك تعليقاً أدناه، وسأجيب عليك مباشرة.
